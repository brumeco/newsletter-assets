# Brum Eco Racing | Newsletter Archive

This repository contains the HTML newsletters and associated media assets for **Brum Eco Racing**, the University of Birmingham's Shell Eco-marathon team.

It serves as a public archive of our newsletters, documenting the team's progress, technical developments, competitions and activities.

The repository also uses GitHub Pages to host newsletter images and other assets, ensuring they remain accessible when embedded in emails.

Newsletters are organised by year and month, alongside a reusable HTML template and shared branding assets.
